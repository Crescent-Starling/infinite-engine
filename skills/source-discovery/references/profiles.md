# Source profiles

Choose by scope and goal, not Domain origin. Record the selected profile and rationale in the coverage assessment. Adapt priorities; do not require every category.

| Profile | Useful coverage | Main cautions |
|---|---|---|
| academic | Open introductory texts, institutional references, societies, scholarly indexes, primary research for deeper questions | An index is not the indexed article; publisher reputation does not validate every claim |
| technical | Official versioned documentation, standards, examples, structured specifications | Track product/release applicability; code execution is a separate permission |
| humanities | Primary texts, critical editions, bibliographies, scholarly commentary | Edition, translation, attribution and interpretive differences matter |
| interest | Official resources, specialist/community references and user material | Label community provenance; usefulness need not imply academic authority |
| astronomy | Academic profile plus data catalogs and multimodal explanatory resources when needed | Separate data releases, imagery rights and explanatory claims |
| latin | Humanities profile plus grammars, lexicons, corpora and morphology data | Distinguish lemma, edition, examples and corpus-specific reuse terms |
| fitness-nutrition | Academic profile plus guidelines, systematic reviews and structured food/activity data | Record population, units, conditions and evidence limitations; no unsupported individualized health advice |
| stellaris | Interest/technical profiles plus official patch notes and community rule references | Pin game version, DLC and mods where known; fictional rules are not evidence of real-world science |

Explore usually prioritizes orientation; Understand benefits from systematic explanations; Apply needs examples and applicability; Advance may need primary research or deeper technical references. These are adjustable recommendations, not automatic source acceptance or mastery scores.
